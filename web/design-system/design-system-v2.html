Enterprise Shared Workspace · v2 · August 2026

Content leads. Chrome recedes.
Governance stays legible.

v2 replaces the 2014-era shell (bordered top bar, bright sidebar, static toolbar strip, docked panel) with the layout grammar of the products people actually copy in 2026 — Linear, Vercel/Geist, Attio, Notion — plus an AI surface that sits beside the work instead of in another tab. Every screen below is built from the same tokens; switch brand and theme above.

Sidebar recedesSits on the canvas, no border, dimmer text, 14px icons. Content is a raised sheet with rounded corners.
Structure felt, not seenHairline 1px shadow-borders, no vertical dividers, separators only where they carry meaning.
Location bar ≠ view barBreadcrumb + share/actions on one line; tabs, filter, display controls on the next. Predictable places.
36px rows, keyboard-firstDense but calm. ⌘K palette, single-key shortcuts, hover-revealed actions, no full-page reloads.
Floating, not dockedSelection toolbar floats over content; details open as a peek panel; controls sit above content, not in boxes.
AI beside the workAsk panel with visible scope, inline citations with hover preview and deep-link to the passage. Agents are audited members.
00

What changed from v1

Every change maps to a specific 2026 reference, not taste. Sources in DESIGN_SYSTEM.md §1.

Top bar spanning full width, borderedv1 → v2 Workspace switcher and search move into the sidebar; the sheet has a slim location bar instead. Fewer competing bars.
Bright sidebar with 16px icons and active fillv1 → v2 Canvas-coloured, borderless, muted text, 14px icons, hover-revealed shortcuts. Content takes precedence (Linear, Mar 2026).
Static command bar stripv1 → v2 Floating selection bar appears only when something is selected; shortcuts inline. Zero chrome when idle.
Docked 360px details panelv1 → v2 Peek panel slides in on Space/click, closable, with an Ask about this file box at the bottom. Panel width persists.
Solid borders, 40px rows, cool blue-greyv1 → v2 Warm greys, shadow-as-border, 36px rows, no vertical rules; hover states carry structure (Geist, Linear).
Split-hero login, three-column mobilev1 → v2 Single centred card, passkey first, one primary action; mobile uses a floating pill tab bar and bottom sheet.

PNWhat are the termination terms with Helios, and did the amendment change them?
Answer · from 2 documents you can open

Either party may terminate the master agreement for convenience with 90 days' written notice1. Amendment 01 shortens that to 60 days, but only for the Warehousing Schedule2; all other schedules keep 90 days. Termination for material breach still requires a 30-day cure period after written notice1.

Nothing in either document changes the notice method — written notice to the registered address remains required1.

Interaction patterns

Same job → same pattern in every view type and entry point. These replace v1's bordered notices and static bars.

Selection bar

Appears only with a selection; floats over content at bottom-centre; shows count, 4–6 actions with single-key shortcuts, overflow, and clear. Denied actions stay visible, dimmed, with a reason on hover.

3 selected

Peek before open

Space or single-click opens the peek panel inside the sheet; Enter opens full. Peek carries preview, label + effect pills, tabs, and Ask about this file. Prev/next arrows walk the list without closing.

Label & effect language

Classification = tinted pill with a dot; the bare dot travels into dense places (sidebar, palette, mobile). Effects = neutral pills tinted only when they restrict. Never colour alone; hover explains source (explicit / inherited / auto) and scan state.
